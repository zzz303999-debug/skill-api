## 1. 业务诉求（用户原话演进）

1. 「费用项不能写死，动态根据模版添加费用项」——已实现（模板声明源化）。
2. 实测 jinxin 账单出现模板外费用列（加班费/报关费/查验费）只进
   `meta.unmatched_headers` 不落单 → 用户拍板「要动态」——已实现：数字

3. 上一轮答复向用户声明「junyu 等标准字段家族不自动落单、需人工补模板

   **标准字段家族是否已收录、若已收录其落单形态是否符合业务预期**。

## 2. 现状行为矩阵（2026-09-04 代码实证）

账单文件里出现「模板 fees 段未声明的费用列」时，按模板/表头形态分流：

| 表头/模板形态 | 代表家族 | 模板外费用列行为 | 落单形态 |
|---|---|---|---|
| 旧 schema（费用名直配，BillRow 链） | jinxin/通寰/builtin | 改前：只上报 unmatched；**改后（本轮）**：数字未知列自动直收 | `shou[0][费用名][money]` 中文名直传 TMS（抓包实证形态），**TMS 侧即显原名** |
| 标准字段·column_range（单行表头） | junyu、zhiyi、qiuyi 等 | **早已全自动收录**（columns 未映射列即费用列，排除序号/锚点/备注/IGNORED/模板 ignore_headers） | `canonicalize_fee` 未命中 mapping/别名 → **默认 to_other**：码=other（TMS 费用档案「其它费」）+ import=True，**原名进通道级 note**（「原名 ¥金额」列表，TMS 备注可见） |
| 标准字段·单行+ranges | yinghui 等 | **早已全自动收录**（区块范围内全部列，mapping 只管码解析） | 同上 to_other |
| 标准字段·two_row（区块行） | haichuan123、yahao 等 | **早已全自动收录**（区块 ∈ channels 的列即费目列） | 同上 to_other |
| L3 AI 候选模板（无 fees 段） | 新家族未固化 | 费用列上报 `new_fee:` 前缀 unmatched，**不落单**（待人工固化模板补 fees 映射） | — |

**实测证据**（junyu 表头 + 追加「加班费/报关费」数字列）：
```
费用条目: freight(运费列) ¥120 | other(加班费列 ¥80)    ← 加班费已自动收录
unmatched_headers: []                                     ← 不上报
```
注：canonical 家族解析层**不存在列发现缺口**——费用区未映射列全部收进，
未命中字典的走 to_other（金额不丢、原名进 note）。上一轮答复称「junyu 不
自动落单」系误报，特此更正。

**唯一会丢/拒的两种情况：**
- 模板 fees 段显式配 `unmapped_fee: skip_report`（当前 8 家族零配置，仅
  negative_policy 内部使用；属「有意忽略」开关，非默认）；
- L3 新家族未固化：费用列不落单、以 `new_fee:` 上报（2026-09-04 审查修复
  后白名单内命中列同样上报，不静默丢）。

## 3. 目标形态（差异点即决策点）

### 3.1 jinxin（BillRow）链——已实现 ✅（2026-09-04）

- 数字未知列自动直收直传（解析层 + 提交层同构），纯文本未知列仍上报。
- 边界：canonical 链不适用（码机制），见 §3.2。

### 3.2 canonical 链——模板外归 other 收录（已定稿）

- 模板外费用列：自动收录（解析层三分支全覆盖）→ 归并「其它费」档案 + 原名
  进通道级 note（金额不丢、备注可查），不建档独立费目；
- 费用动态建档仅模板内声明费目（canonical 链 T25，现状）。

### 3.3 jinxin（BillRow）链——模板外费用自动建档（2026-09-04 用户拍板，本轮实现）

实测暴露三层差异：订单费用按名直传可录（TMS 不校验档案），但 TMS「费用
管理」只有 AddCarPrice 建档过的费目——**模板外新费目订单有、费用管理无档案**。
用户拍板：**create 时自动 AddCarPrice 建档同名档案**（费用管理出现加班费等）：

- 候选 = 本批订单 shou 名中无已建档档案者（别名命中且 registry/YAML 有
  price_id → 跳过幂等）；未建档名建档（字典码或动态码 x+sha1[:8]）；
- **preview 零副作用**：只出 planned 计划清单不发请求；
- 建档失败/端点未配：**不阻塞下单**（直传不依赖 price_id，仅报告下批重试）；
- 幂等：registry 登记/ exists_external（204）后跨批不再建档。

### 3.4 L3 新家族（未固化模板）费用列

维持 new_fee 上报待人工固化（既有护栏），不自动直收、不建档。
