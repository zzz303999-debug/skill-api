# 模板配置初稿 · 8 个应收家族（业务信息 → TMS 业务订单）

> 生成方式：从 37 个样本文件的**实测表头**程序化生成，167 个字段映射全部经真实表头校验通过。
> TMS 必填确认（2026-08-13）：**提单号 `bl_no` + 箱型 `box_type_qty`** —— 8 个家族原生 100% 覆盖，无缺口。
> Schema 说明见《竞品账单解析-TMS业务订单接入设计》§3；归一化规则语义见该文档 §5。

## 必填校验策略

```yaml
# 每份配置的 required 段统一为：
required: [bl_no, box_type_qty]
# 缺失处理：预览模式该行标红并进 missing_fields；create 模式该行跳过、不阻断其他行下单（与既有失败隔离语义一致）。
```

## 指纹算法约定

`fingerprint = md5(表头行所有非空单元格归一化后以 '¶' 连接)[:8]`；归一化 = 去除所有空白字符。
L1 精确命中 `fingerprints` 列表；未命中时按列名集合与 `family_min_overlap: 0.85` 做族级近似（应对秋怡/志驿的逐年漂移）；再未命中走 L3 AI 映射固化。
