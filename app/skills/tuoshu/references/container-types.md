# 集装箱箱型归一

托书原文的箱型表达非常混乱，统一映射到 ISO 6346 常见类型代码。

## 归一表

**归一后的标准值**（用于 `containers[].type`）：

| 标准值 | 含义 | 原文写法（不完全枚举） |
|--------|------|---------------------|
| `20GP` | 20 尺普通箱 | 20GP / 20'GP / 20DV / 20DC / 20GENERAL / 20普 / 20尺普通箱 |
| `40GP` | 40 尺普通箱 | 40GP / 40'GP / 40DV / 40DC / 40普 |
| `40HC` | 40 尺高箱 | 40HC / 40HQ / 40'HC / 40'HQ / 40H / 40高 / 40高箱 |
| `40HQ` | 40 尺高箱（部分公司习惯写 HQ） | 与 40HC 等价；**统一输出 `40HC`** |
| `45HC` | 45 尺高箱 | 45HC / 45HQ / 45'HC / 45高 |
| `20RF` | 20 尺冷冻箱 | 20RF / 20REF / 20冷冻 |
| `40RF` | 40 尺冷冻箱 | 40RF / 40REF / 40冷冻 / 40RH |
| `20OT` | 20 尺开顶箱 | 20OT / 20OPEN TOP |
| `40OT` | 40 尺开顶箱 | 40OT / 40OPEN TOP |
| `20FR` | 20 尺框架箱 | 20FR / 20FLAT |
| `40FR` | 40 尺框架箱 | 40FR / 40FLAT |
| `20TK` | 20 尺罐箱 | 20TK / 20TANK |

## 关键决策

**`40HC` vs `40HQ`**：ISO 官方代码是 `40HC`（High Cube），但中国内贸/货代圈普遍写 `40HQ`。

- **统一输出 `40HC`**
- 若业务系统需要 `40HQ`，由调用方在入库前替换
- 原文即使写 `40HQ`，也归一为 `40HC`

## 拆分规则（详见 field-aliases.md）

原文 `1*40HC` / `2×40HQ` / `40HQ*9` / `1X40HQ` / `20GPX1` 均按以下方式拆：

- 提取数字部分为 `qty`
- 剩余部分匹配上表得到 `type`
- 分隔符：`*` `×` `X` `x`

复合柜量：

- `1*40HQ + 2*40GP` → `[{type:"40HC", qty:1}, {type:"40GP", qty:2}]`
- `1X40HQ+2X40GP` → 同上
- `3*40HC` → `[{type:"40HC", qty:3}]`（一条记录，qty=3）

## 特殊标识

- `40'` 中的 `'` 是英寸符号，去掉即可（`40'HC` → `40HC`）
- `HC` 前的空格忽略（`40 HC` → `40HC`）
- 全角 `＊` 视为 `*`

## 未识别箱型

原文出现罕见箱型（如 `20SD`/`40SD`），保留原文并在 `raw_text_snippet` 说明，`type` 输出原文大写去空格。
