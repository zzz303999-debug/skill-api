# 集装箱箱型识别与原文保留

托书原文的箱型表达可能不同，但 `containers[].type` 必须保存原文业务代码。
系统可以识别等价含义，但不得在输出字段中替换代码。

## 识别表

**已知识别值**（仅用于识别和校验，不用于改写）：

标准短代码固定为 4 位：箱长 `20`/`25`/`40` 加两位字母后缀。支持
`GP`、`HC`、`HQ`、`RF`、`OT`、`TK`、`FR`、`PL`、`OH`、`RH`、`UT`、`VH`
等原文代码；既有 `45HC` 和 `20GENERAL` 等代码继续按原文保留。

| 识别类别 | 含义 | 可识别原文代码（输出各自原值） |
|--------|------|---------------------|
| `20GP` | 20 尺普通箱 | 20GP / 20'GP / 20DV / 20DC / 20GENERAL / 20普 / 20尺普通箱 |
| `40GP` | 40 尺普通箱 | 40GP / 40'GP / 40DV / 40DC / 40普 |
| `40HC` | 40 尺高箱 | 原文为 40HC 时输出 `40HC` |
| `40HQ` | 40 尺高箱 | 原文为 40HQ 时输出 `40HQ`，不得改成 40HC |
| `45HC` | 45 尺高箱 | 45HC / 45HQ / 45'HC / 45高 |
| `20RF` | 20 尺冷冻箱 | 20RF / 20REF / 20冷冻 |
| `40RF` | 40 尺冷冻箱 | 40RF / 40REF / 40冷冻 / 40RH |
| `20OT` | 20 尺开顶箱 | 20OT / 20OPEN TOP |
| `40OT` | 40 尺开顶箱 | 40OT / 40OPEN TOP |
| `20FR` | 20 尺框架箱 | 20FR / 20FLAT |
| `40FR` | 40 尺框架箱 | 40FR / 40FLAT |
| `20TK` | 20 尺罐箱 | 20TK / 20TANK |

## 关键决策：禁止改写

`40HC`、`40HQ`、`40DV`、`40GP` 等值必须按原文输出。即使业务含义相近，
抽取层也不能替客户修改代码。若 AI 输出与原文不同，规则层按原文恢复并生成
`container_type_not_verbatim` 记录。

## 拆分规则（详见 field-aliases.md）

原文 `1*40HC` / `2×40HQ` / `40HQ*9` / `1X40HQ` / `20GPX1` 均按以下方式拆：

- 提取数字部分为 `qty`
- 剩余部分逐字保存为 `type`
- 分隔符：`*` `×` `X` `x`

复合柜量：

- `1*40HQ + 2*40GP` → `[{type:"40HQ", qty:1}, {type:"40GP", qty:2}]`
- `1X40HQ+2X40GP` → 同上
- `3*40HC` → `[{type:"40HC", qty:3}]`（一条记录，qty=3）

## 特殊标识

- 不得把 `HQ` 改成 `HC`，也不得把 `DV` 改成 `GP`
- 尺寸标点和排版空格可以清理，例如 `40' HQ` 输出 `40HQ`，但 `HQ` 后缀不变
- 数量分隔符可以解析，但箱型代码本身以原文为准
- 全角 `＊` 视为 `*`

## 未识别箱型

原文出现识别表外箱型（如 `40NOR`/`20SD`/`40SD`），`type` 保留原文代码，并生成 non-blocking `unknown_container_type` 复核提示。
