竞品账单导入 · 用户操作手册

上传竞品应收对账单，一键生成 TMS 订单

适用页面：竞品账单导入

1快速上手

总共三步，全程在「竞品账单导入」页面完成

1

打开导入页面

浏览器访问 网址（竞品账单导入页面）

2

上传账单文件

拖拽 Excel 账单到页面，或点击选择文件；支持 .xls / .xlsx / .xlsm，单个文件不超过 20MB

3

选择录入模式，点击按钮

按下方说明选好「仅预览解析」或「解析并创建订单」，点击按钮开始

2录入模式（可切换）

上传文件后、点按钮前，随时可以在两种模式间切换

模式 行为 什么时候用
仅预览解析 只解析账单并展示归集结果，不触达 TMS 系统，不会创建任何订单 先核对账单解析得对不对，安全试跑
解析并创建订单 解析后直接逐单创建 TMS 订单，账单正式录入系统 要下到 TMS 里，就选这个

重点提示：正在创建订单 = 已经录入了

选择「解析并创建订单」并点击按钮后，按钮会显示 正在创建订单…。看到这个提示，说明账单已经在逐单录入 TMS 了——可以直接去 TMS 里查看订单，不用管这个页面，等页面提示完成即可。

3创建结果怎么看

「解析并创建订单」完成后，页面会汇总每一单的结果

—
结算区间
—
数据行数
—
归集订单
—
创建结果

创建结果按「新建 / 跳过 / 失败」计数，含义如下：

新建：本单已成功创建进 TMS（表格状态显示「成功」，含业务编号） 跳过：该提单号此前已创建成功，不会重复创建 失败：本单未创建成功，不影响其他订单，可修正后重新导入

4常见问题

重复上传

同一账单重复上传会提示「账单已全部创建过」，不会重复创建订单

文件不支持

提示「不支持的文件格式」时，请确认文件是 .xls / .xlsx / .xlsm 格式。

文件太大

单个文件超过 20MB 会被拒绝，请拆分后重试。

数据太多

单次导入超过 10000 行数据会被拒绝，提示「数据量过大」，请拆分后分批导入；仍无法解决请联系人工客服。

一票多柜

同一提单号的多个柜子会自动合并为一个订单，无需手动处理。

无法连接服务

提示网络错误时，请检查页面与服务是否部署在同一地址、服务是否已启动

仅预览模式不会创建任何订单；重复上传已创建过的账单将提示重复导入。
